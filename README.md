# 星轨 STARWAY · 官网

独立游戏工作室「星轨 STARWAY」的品牌官网。纯静态站点，无构建步骤、无依赖，直接用浏览器打开即可运行。

除了游戏品牌本身，站内还承载两个「不是产品」的部分：**星轨计划**（公益资助，国内 + 海外）与**世界和平**（独立页面，收录《联合国宪章》与《世界人权宣言》全文）。

## 页面

| 文件 | 页面 | 说明 |
| --- | --- | --- |
| `index.html` | 首页 | 作品、开发者日志、星轨计划入口、世界和平完整区块（价值观 / 两份联合国文件 / 我们的行动） |
| `starway.html` | 星轨计划 | 国内与海外项目、受助人、捐款渠道、善款公示 |
| `donate.html` | 捐赠详情 | 受助人照片与故事、筹款进度、项目进展、收款码；需登录 + 实名 |
| `peace.html` | 世界和平 | 独立视觉体系（联合国蓝 + 衬线排版），五语，收录两份联合国文件全文 |
| `minors.html` | 未成年人模式 | 游戏角、时长提醒、支付限制；需登录 + 实名 |
| `register.html` | 实名注册 | 三步注册，未满 18 岁走监护人授权 |

## 主要能力

**多语言** — 中文 / English / Русский / Français / العربية 五种语言，可自由切换，阿拉伯语自动 RTL。文本集中在 `assets/lang.js`（页面文案）、`assets/charter.js`（宪章）、`lang.js` 内的 `UDHR`（人权宣言）三处。

**无障碍** — 右下角悬浮面板，覆盖：
- 大字体 / 内容放大（标准 / 大字 / 特大三档）
- TalkBack 屏幕朗读、随选朗读（文字转语音）
- 图片描述、字幕、语音识别文字
- 高对比度文字、颜色反转、色彩视觉增强（色弱 / 色盲）、减少动效
- 左右音频声道（立体声 / 仅左 / 仅右 / 单声道）

设置存 `localStorage`，跨页面保持；也支持深链，例如 `peace.html?a11y=open,contrast`。

**实名与未成年人保护** — 捐赠与未成年人相关页面在未登录 / 未实名时全屏锁定；未成年账号禁止支付，引导使用监护人账号。

**背景音乐** — WebAudio 实时合成，无音频文件；首次交互后自动播放，可随时暂停。

## 本地运行

直接双击 `index.html` 即可。若需要以 http 方式预览：

```bash
python -m http.server 8000
# 打开 http://localhost:8000
```
